# Lumina Café ☕ — Website Template

A modern, elegant website template for artisanal coffee shops and cafés. This is a fully customizable starter template designed to showcase coffee businesses with style and sophistication.

## About This Template

This is a reusable project template that can be customized for any coffee shop or café business. Simply replace placeholder content, colors, images, and contact information with your own.

## Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Dark Mode Toggle** - Switch between light and dark themes with persistent preference storage
- **Elegant UI** - Warm, inviting aesthetic with smooth animations
- **Full Menu** - Browse our signature brews and pastry selection
- **Interactive Navigation** - Smooth scrolling and mobile-friendly hamburger menu
- **Contact Form** - Built-in form validation for inquiries and reservations
- **Customer Testimonials** - Social proof section showcasing reviews
- **SEO Optimized** - Meta tags and Open Graph support for better discoverability
- **Social Media Integration** - Clickable social media links in footer
- **Back to Top Button** - Easy navigation for long pages
- **Fast & Lightweight** - No frameworks, pure HTML, CSS, and JavaScript

## Getting Started

### For Template Users:

1. Clone or download this repository
2. Customize the following:
   - Update café name, colors, and branding in `css/style.css`
   - Replace all placeholder text with your café's information
   - Add your own images to `assets/images/`
   - Update contact details, hours, and location
   - Modify menu items and pricing
3. Open `html/index.html` in your web browser
4. Deploy to your web hosting service
